## 🎬 Recording Tips for Winning
1. **Screen Resolution**: Record at 1920x1080 60fps.
2. **Pacing**: Keep narration crisp and confident—do NOT linger on loading states.
3. **Show, Don't Tell**: When talking about the Strands agent chain, keep the **Agent Reasoning** terminal visible so judges see the actual agent thoughts streaming in real-time.
4. **Contrast the Routine vs. Anomaly**: Emphasize that **95% of tasks pass silently**—judges grade heavily on the hackathon theme of background autonomy without human interruption.
